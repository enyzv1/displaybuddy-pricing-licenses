## 买之前要知道的几个限制

**授权跟 Mac 走，不跟人走。** 同一台 Mac 上开了两个用户账户，每个账户都要单独授权。合租机器、家里几个人共用一台 iMac 的，这一点提前算进去。

**退款只保原价单。** 官网的 7 天退款写明仅限全价购买，用码下单的不在这条承诺里。国内渠道走自己的退款规则，别拿官网那条当依据。

**亮度控制依赖 DDC-CI 协议。** 显示器不支持这个协议，装上也没用；音量和对比度只有部分显示器能调，不是每块屏都能完整控制。买之前先确认你的显示器支持 DDC-CI，不要指望它什么屏都能调。

**买断不等于永久免费升级。** 2.0 大版本更新时老用户是免费升的，这点当年说得很明确。以后每个大版本是否还这样，买之前不要默认。

**功能边界要清楚。** 它做的就是显示器的亮度、音量和输入源控制，外加预设和快捷键，不是系统增强工具，替代不了窗口管理或者色彩校准软件。
